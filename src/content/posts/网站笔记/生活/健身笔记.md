# 训练安排
### 周一：胸 + 三头

1. 平板杠铃 / 哑铃卧推 4 组 ×12 次
2. 上斜哑铃卧推 3 组 ×12 次
3. 绳索夹胸 3 组 ×15 次
4. 窄距俯卧撑 3 组 × 力竭
5. 绳索下压（三头）4 组 ×15 次
6. 仰卧臂屈伸 3 组 ×15 次

### 周二：背 + 二头

1. 引体向上 / 高位下拉 4 组 ×12 次
2. 杠铃划船 4 组 ×12 次
3. 单臂哑铃划船 3 组 ×12 次 / 侧
4. 直臂下压（背阔）3 组 ×15 次
5. 杠铃弯举 4 组 ×12 次
6. 哑铃交替弯举 3 组 ×12 次 / 侧

### 周三：休息日

- 不力量训练
- 饭后慢走 20 分钟
- 正常按食谱吃，不节食、不加餐乱吃东西

### 周四：肩 + 腹

1. 哑铃推举 4 组 ×12 次
2. 侧平举 4 组 ×15 次
3. 俯身飞鸟（后束）3 组 ×15 次
4. 哑铃耸肩（斜方）3 组 ×15 次
5. 平板支撑 3 组 ×60 秒
6. 卷腹 + 抬腿 各 3 组 ×20 次

### 周五：腿 + 臀（瘦人必练腿，促全身长肉长肌）

1. 深蹲 4 组 ×12 次
2. 弓步蹲 3 组 ×12 次 / 侧
3. 腿屈伸 3 组 ×15 次
4. 腿弯举 3 组 ×15 次
5. 提踵（小腿）4 组 ×20 次

### 周六：全身复合塑形（巩固薄肌线条）

1. 俯卧撑 4 组 × 力竭
2. 俯身哑铃划船 4 组 ×12 次
3. 哑铃侧平举 3 组 ×15 次
4. 徒手深蹲 3 组 ×15 次
5. 核心循环：卷腹 + 俄罗斯转体 各 3 组

### 周日：休息日

- 完全放松，只日常走动
- 睡眠保证 7 小时以上，**睡眠是瘦人增肌关键**
